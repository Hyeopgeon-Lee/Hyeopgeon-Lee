## 🚀 Current Interests

최근에는 다음 기술과 교육 방법에 관심을 가지고 있습니다.

- **AI Agent Engineering** — 모델뿐 아니라 Tool, Context, Memory, Workflow를 포함한 에이전트 시스템 설계
- **Private AI / Enterprise RAG** — 기업 내부 데이터를 활용하는 안전한 AI 서비스
- **AI + Software Engineering** — 생성형 AI를 활용한 소프트웨어 개발 생산성 및 품질 향상
- **Cloud Native AI** — AI 서비스를 Kubernetes와 클라우드 네이티브 환경에서 안정적으로 운영
- **Data Engineering for AI** — AI 서비스를 위한 데이터 수집·처리·검색·파이프라인 설계
- **DevOps / Platform Engineering** — 개발부터 배포·관측·운영까지 연결하는 자동화 환경
- **Project-Based Education** — 실제 서비스 구현과 포트폴리오 중심의 소프트웨어 교육
